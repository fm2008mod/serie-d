# FM2008 Serie D Activation Patcher

**Languages:** [English](README.md) · [Polski](README.pl.md) · [Italiano](README.it.md) · [Español](README.es.md)

A small Windows program that patches **Football Manager 2008** (`fm.exe`, version **8.0.2 / 8.0.2f117931**) so the Italian **Serie D** becomes playable.

## What it does

- Activates the dormant Serie D (the 9 groups) so clubs, fixtures, tables, promotion and relegation work in-game.
- Works on the **original** `fm.exe` and on the **no-DVD** `fm.exe` (same version). The result has the DVD check disabled.
- **Never modifies your original file.** It writes a new file named `<name>_serieD.exe` next to it.
- Before writing anything it checks the file size and every byte it is about to change. If something does not match, it stops and writes nothing.

## How to use

1. Make a **backup** of your game's `fm.exe`.
2. Download `FM2008_SerieD_Patcher_EN.exe` and put it in the same folder as `fm.exe` — **or** drag `fm.exe` onto the patcher.
3. Run the patcher. It creates `fm_serieD.exe`.
4. Rename `fm_serieD.exe` to `fm.exe` (or launch it directly) in the game folder.
5. Start a **NEW game** and enable Italy as a loaded nation (with its lower leagues available in the database).

> A save game started with an unpatched `fm.exe` will not gain Serie D; you need a new game.

## Troubleshooting

| Message | Meaning |
|---|---|
| `wrong file size` | The file is not fm.exe 8.0.2f117931 (original or no-DVD), or it is already patched. |
| `bytes at 0x... do not match` | A different crack/modification of the exe. Nothing was written. |
| `output file ... already exists` | Delete or rename the existing `*_serieD.exe` first. |
| Windows SmartScreen / antivirus warning | The program is unsigned. You can inspect the source or compare the output with a known patched build. |

## Notes

- 32-bit game executable; the patcher itself is a small standalone Windows program, no installation needed.
- The patcher contains only the **differences** (a few bytes plus a small code section). It does not contain the game. You need your own copy of the game.
- The Spanish Tercera División work is a separate, still experimental project and is **not** part of this patcher.
- Use at your own risk. Not affiliated with Sports Interactive or SEGA.
